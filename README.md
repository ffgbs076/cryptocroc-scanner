# CryptoCroc Scanner

Bull & Bear small-cap crypto scanner.

## Wat doet dit?
- Scant small caps via CoinGecko
- Meet orderboek via Bitget (primair) + Binance (confirm)
- Splitst Bull & Bear op basis van BTC
- Radar → Buildup → Almost → Entry → Hold/Sell
- Draait automatisch via Vercel Cron

## Tech
- Next.js (App Router)
- Node.js 18
- Vercel KV
- Vercel Cron
